# japan-vps-watch

每 30 分钟扫描一次：有没有**日本 VPS 年付 ≤ $8** 或**香港 VPS 年付 ≤ $8**、并且**有货能买**。

## 付款方式（铁律）

只算能用万事达借记卡直接付款的商家。只收加密货币、只收 PayPal、只收手动转账的一律不算——再便宜也没用。扫描器只能验库存和价格，付款方式须在通知买家之前人工核实。

## 怎么看结果

- **`HIT.md`** — 有命中时列出商家、套餐、价格、配置、证明链接（商家自己的下单页）和发现时间。没有命中时写明 "No current hit"。
- **`state.json`** — 每次扫描的完整状态：每个目标是 `in_stock` / `out_of_stock` / `unreachable` / `unknown_js`，以及看到的价格。

## 命中规则（很严）

必须是商家自己的 live 下单页同时确认两点才算命中：

1. 有货（能下单 / 日本或香港可选）；
2. 年付价格 ≤ 上限（日本 $8.00/年，香港 $8.00/年）。

广告、论坛帖、搜索摘要里的价格**永远不算**命中。超过上限的也不算。

## 已知的检测局限（实话）

- natkvm 常规下单页的"选择机房"下拉菜单是 JS 加载的，普通 HTTP 抓不到；所以 natkvm 日本的主信号是活动页（服务端渲染的 "Out of Stock" 文字），活动页一恢复就有货。香港的命中来自浏览器实测（下拉菜单可选 + $5.50），不是纯抓取。命中后下单前请在浏览器里再确认一次地点可选。
- LowEndTalk 黑五大帖在数据中心 IP 上基本是 Cloudflare 403，扫描器只会记一笔 `blocked`，不报错。
- VirNAT 的网站 DNS 已死，恢复之前只能记 `unreachable`。

## 运行方式

GitHub Actions 定时任务（`.github/workflows/scan.yml`），每 30 分钟跑一次 `scan.py`（纯 Python 标准库），每次提交 `state.json`，有命中时写 `HIT.md`。也可以在 Actions 页面点 "Run workflow" 手动跑一次。
